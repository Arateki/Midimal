# Fonts

**Montserrat** is the official Arateki typeface (designed by Julieta Ulanovsky, licensed under SIL OFL 1.1).

The full Montserrat family is now self-hosted in this folder as 18 TTF files covering weights 100–900 plus italics. They are registered via `@font-face` in `colors_and_type.css` — no network request, fully offline-capable.

### Available weights
- 100 Thin · 200 ExtraLight · 300 Light · 400 Regular · 500 Medium
- 600 SemiBold · 700 Bold · 800 ExtraBold · 900 Black
- All weights include italics.

### Brand manual specifications
- Logo text: **Montserrat Regular 400**, 62pt, letter-spacing 34 (≈0.34em)
- Titles: **Bold 700**, 20–32pt
- Subtitles / accents: **Medium 500** uppercase with wide tracking
- Body copy: **Regular 400**, 9–11pt print, line-height 1.5–1.7

### Mono
`JetBrains Mono` is the recommended monospace pair for code and technical UI (not bundled in the kit).
